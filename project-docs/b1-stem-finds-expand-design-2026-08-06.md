# B1 어간 finds 전개 (Kiwi joinSent) — 설계

- 날짜: 2026-08-06
- 상태: **구현** (`npm run kiwi:expand-b1-finds`)
- 관련: 맞춤법 시트 `dividerGroup=B1` · `kiwi-nlp` `joinSent` · freeze(매칭 로직 금지, 데이터 보정 허용)

## 0. 한 줄

B1(`잘못된 표현(동사 · 형용사)`)만, **오프라인**에서 Kiwi `joinSent`로 관형·연결 표면을 만들어 **같은 행의 `finds`에 합친다.**  
런타임 매칭·규칙 수는 그대로. 교정은 **기존과 같이 어간형 replace(C)**.

## 1. 동기 · 직무

| | |
|--|--|
| **동기** | 시트에 `우겨넣`만 넣어도 `우겨넣은`·`우겨넣을`을 **검출** (관형 포함). 맞춤법 find를 표면형으로 다 나열하지 않음. |
| **직무** | 맞춤법 검사 find 목록 확장. 표기통일 noise-list 꼬리와 **출력·코드 경로 분리**. |
| **비목표(이번)** | `우겨넣은→욱여넣은` 전체 표면 치환(B: 런타임 접미 이식) — 베타 freeze 협의 후. |
| **수용** | `우겨넣은→욱여넣` — `덮히→덮이`와 동일한 출시 동작(C). |

## 2. 원칙 (직전 합의와의 정합)

1. **규칙 수 곱하지 않음** — 어미마다 행을 쪼개지 않음. `finds` 확장만.
2. **매칭 엔진 변경 없음** — `compileSpellingFindsAlternation` / ruleEngine 그대로 (freeze 회피).
3. **수확 우선** — sync와 분리된 스크립트(또는 sync 플래그)에서 Kiwi 사용. noise-list harvest와 같은 패턴.
4. **전면 A(행 분리) 채택 안 함** — 받침 불일치 행은 자동 전개 **스킵 + 시트 수동만**.  
   “지금은 미룸”이 아니라 **자동 경로에서 A를 쓰지 않기로 확정.** 유사 사례가 늘어도 기본은 동일. A 재도입은 별도 설계·승인.

### 받침 불일치 스킵 목록 (2026-08-06 집계)

| find | replace | 이유 |
|------|---------|------|
| 안절부절하 | 안절부절못 | 받침 불일치 · 어간쌍 부자연 |
| 잊혀 | 잊힌 | 받침 불일치 |
| 짜여진 | 짜여 | 받침 불일치 · 이미 활용형 표면 |

`우겨넣`↔`욱여넣`은 **받침 동일** → finds 전개 + C 대상.

## 3. 흐름

```
spelling-rules.json (또는 sync 직후 메모리)
  → dividerGroup === 'B1'
  → 스킵 가드(아래)
  → joinSent(findStem, endingMorph) × 화이트리스트
  → joinSent(replaceStem, endingMorph)는 이번 미사용(C: replace 고정)
  → 유효 표면 ∪ 기존 finds ∪ [find]
  → 같은 행 finds[] 갱신 (길이 ≥2면 묶음 규칙)
  → JSON 저장
```

권장 엔트리: `npm run kiwi:expand-b1-finds`  
(`scripts/expand-b1-spelling-finds.mjs`, `loadKiwiNode` 재사용)

## 4. 어미 화이트리스트 (1차)

form은 **한글만** (단독 `ㄴ`/`ㄹ` 금지 — `우겨넣ㄴ` 방지).

| form | tag | 역할 |
|------|-----|------|
| 은 | ETM | 관형 (우겨넣은 · 덮힌) |
| 는 | ETM | 동사 관형 |
| 을 | ETM | 관형 (우겨넣을) |
| 고 | EC | 연결 |
| 어 | EC | 연결 (join이 모음조화·해) |
| 아 | EC | 연결 |
| 었 | EP | 과거 |
| 았 | EP | 과거 |

어간 태그: **VV · VA** 각각 시도 후 표면 **합집합** (품사 열 없음).

## 5. 가드

- 띄어쓰기 있는 find → 스킵  
- replace에 `또는` 또는 공백 → 스킵 (다중 교정어)  
- §2 받침 불일치 3행 → 스킵  
- 전개 제외: `스런`, `꺼야`, `오랫만`, `삼가토록`  
- 이미 관형 표면(`…는/은/을/던/된`) → 스킵 (`걸맞는` 등)  
- 생성 표면 폐기: 비한글·자모 포함·빈 문자열·어간과 동일(이미 find로 커버)  
- 기존 `finds`와 **합집합** (덮히의 덮혔·덮혀 유지 + 덮힌 추가)

## 6. UI · 한도

- B1 `ruleId` 현재 0건. 활성 키 = `find`(또는 ruleId).  
- **행 1 = 체크 1 = 한도 1.** `finds`만 늘리면 항목 수 불변.  
- A(행 분리) 시 한도·체크가 늘어남 → 이번 범위 밖.

## 7. 스파이크 근거 (요약)

`joinSent` (`kiwi-nlp@0.23.0`):

- `우겨넣`+`은` → `우겨넣은`, +`을` → **`우겨넣을`** (동기 사례 실증)
- `가`+`을` → **`갈`**, `하`+`을` → `할` (을→ㄹ)
- `덮히`+`은` → `덮힌`, +`어` → `덮혀`
- `가`+`은` → `간`, `하`+`어` → `해`
- form `ㄴ`/`ㄹ` → 폐기 대상 문자열

### VV·VA 교차 태그 (합집합 우회 검증)

`joinSent`는 **잘못된 품사 태그를 거부하지 않는다.** 같은 어미면 대개 **동일 표면**이 나온다.

| 시도 | 결과 | 해석 |
|------|------|------|
| `예쁘`+VA/VV+`은` | 둘 다 `예쁜` | 정상 표면 (태그 무관) |
| `예쁘`+VA/VV+`는` | 둘 다 `예쁘는` | **죽은 후보** (원고에 거의 없음) |
| `먹`+VV/VA+`는` | 둘 다 `먹는` | 정상 |
| `좋`+VA/VV+`는` | 둘 다 `좋는` | 죽은 후보 |

결론: 합집합은 “잘못된 태그가 별도 실단어를 만든다”기보다 **중복·죽은 문자열**을 늘린다.  
**우연히 다른 실단어와 충돌**할 잔여 위험은 배제하지 않음 → 골든·모니터링. 충돌이 보이면 해당 find 블록리스트 또는 품사 열로 좁힌다.

## 9. 비범위 · 후속

- **A(행 분리)**: 이번뿐 아니라 **자동 전개 수단으로 채택하지 않음.**  
  `안절부절하`·`잊혀`·`짜여진`(및 이후 유사 받침 불일치)은 **시트 수동 `finds`/행 관리만**.  
  나중에 같은 유형이 늘어도 기본은 스킵+수동이며, A 재도입은 **별도 설계·승인**이 있을 때만.
- B: matched 접미 → replace 어간 join (freeze 협의)  
- 품사 열 — 교차 태그 충돌이 관측될 때  
- 표기통일 verbalTails와 JSON/스크립트 공유 (동기만 문서 교차 참조)
