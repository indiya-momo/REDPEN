# Kiwi P1 구현 메모 (Node 우선)

- 일시: 2026-08-02
- 방식: 권장 **1** — Node/테스트 + 플래그 OFF 기본. 브라우저 104MB 로드는 보류.

## 추가·변경

| 경로 | 역할 |
|------|------|
| `src/lib/kiwiMorph/*` | analyze / strip / userDict / loadNode / mapRestoredToVisual |
| `src/lib/featureFlags.js` | `isUnifyKiwiJosaEnabled` ← `VITE_UNIFY_KIWI_JOSA` |
| `src/lib/unifyCandidateDiscover.js` | `stripTrailingJosaHeuristic` + Kiwi 시도 |

## 검증

- `vitest` kiwiMorph + featureFlags + discover + josaReview: **통과**
- 모델 없으면 Node 스위트 `skipIf`
- `kiwi-nlp`는 **static import를 loadNode만** (브라우저 번들 오염 방지; Match.all=8388671 상수)

## 사용 (로컬)

# tmp/kiwi-models 준비 후
VITE_UNIFY_KIWI_JOSA=true
# 테스트/스크립트에서 loadKiwiNode() 호출 시에만 morph strip 적용
