# 표기 통일 추천 — 목록 정리(규칙 1단계 → SLM 2단계)

**상위:** `unify-candidate-spacing-redesign-2026-07-29.md`, `unify-josa-review-slm-sketch.md`  
**상태:** **1단계 출시 방향** (규칙만). 용언/유지·삭제 SLM은 **2단계 후보**로 보류.  
**작성·개정:** 2026-07-30  
**관련 구현:** `unifyDependentNounGenitive.js`, DEV 「2차 검토」패널.  
**보류 코드:** `unifyPredicateReviewSlm/` (`VITE_UNIFY_PREDICATE_SLM`, 기본 off) — 기존 조사 SLM 배관 재사용 전제.

---

## 0. 왜 순서를 바꿨나

「용언 휴리스틱에 안 걸리면 명사」로 두면 애매 항목(`개의` 등)이 빠져 AI를 쓸 이유가 없다.  
반대로 **지금 당장 새 SLM 큐·cap을 또 깔기**에는, 애매 칸이 **얼마나 큰지 데이터가 없다**.

그래서 **3단 분류**를 먼저 규칙으로 세우고, 애매 칸 빈도를 재본 뒤 SLM을 얹는다.

| 칸 | 의미 | 1단계 처리 |
|----|------|------------|
| **확실한 명사** | 표기 통일 어근으로 둘 만함 | **유지**, SLM 없음 |
| **확실한 삭제** | 닫힌 목록으로 문법상 어근 아님 | **규칙 즉시 삭제** |
| **애매** | 위 둘 아님 | **유지**(안전 기본값). 삭제하지 않음. DEV에 건수 집계 |

잘못 지우면 유효 후보가 사라지고, 잘못 남겨도 사용자가 눈으로 걸러낼 수 있다 → 애매는 **유지가 기본**.

---

## 1. 확실한 삭제 — 의존명사 + 「의」(규칙 즉시)

의존명사(것, 수, 바, 만큼, 뿐, 데, **개** …) + 관형격 「의」는 **닫힌 목록**.  
`이며`/`하도록`을 high tier로 빼 예산을 아끼던 것과 같은 논리.

- 예: `개의` = 개(의존명사) + 의 → **`개의@` 계열 통째 목록 제외**
- 구현: `isDependentNounPlusUi` / `stripDependentNounGenitiveFromGroups`
- DEV 「2차 검토」→ **규칙으로 목록 제외**에 기록

---

## 2. 확실한 명사 (규칙, SLM 없음)

유지·집계용. 삭제하지 않는다.

초안 가드(확장 가능):

- 외래 지명 `-ia` 꼬리 (`캘리포니아` 등) — 기존 `unifyPredicateBucket` 가드와 정합
- 용언 어미·보조 꼬리 휴리스틱에 **안** 걸리고, 한글 어근이 충분히 긴 계열/키

---

## 3. 애매 칸 (1단계 = 유지 + 계측)

- 휴리스틱 용언·짧은 어절·조사처럼 보이는 끝 등, 1·2칸이 아닌 것
- **삭제하지 않음**
- DEV 패널에 **「애매 유지 N」** 과 라벨 목록(샘플) → 베타에서 빈도 확인
- N이 유의미하면 **2단계**에서 SLM

---

## 4. 2단계 (데이터 보고 나서) — SLM

질문이 「용언이냐」만이 아니라 **「목록에 둘 만한 어휘 어근이냐(유지/삭제)」**.

- **새 배관 금지.** `unifyJosaReviewSlm/`의 enqueue·cap·runner·플래그 패턴 재사용  
  (이미 있는 `unifyPredicateReviewSlm/`을 그 방향으로 다듬거나 흡수)
- 큐: **애매 칸만**, cap 10, 우선순위는 조사형 끝(`의`/`가`/`이` 등) → 나머지
- 의존명사+의는 **이미 규칙 삭제**라 큐에 안 넣음(예산 절약)
- UI: DEV 「2차 검토」에 유지/삭제 결과 (현행 인라인 expand)

조사·어간 SLM(`VITE_UNIFY_JOSA_SLM`)은 **별개로 유지**.

---

## 5. UI (DEV만)

라벨: **「2차 검토」** (카나나/SLM 문구 금지)

1단계 접힌 예:

`2차 검토 · 규칙제외 1 · 애매 유지 24 · 조사 …`

펼침:

- 규칙으로 목록 제외 (의존명사+의 …)
- 애매 유지 (계측 — 지금은 삭제하지 않음)
- 조사·어간 (플래그 ON일 때)
- 용언/유지·삭제 모델: **2단계·플래그 ON일 때만**. 1단계에서는 「애매는 유지(모델 미사용)」안내

---

## 6. 비범위 (1단계)

- 애매 칸 SLM 삭제
- 사전 API
- 클라우드 GPU
- 「용언 미등록 = 명사」 취급

---

## 7. 성공 기준 (1단계)

1. `개의@`가 **규칙으로** 목록에서 사라지고 DEV에 기록된다. (모델 불필요)
2. `문화@` 등 확실한 명사 계열은 남는다.
3. 애매 항목은 남고, DEV에 **애매 유지** 건수가 보인다.
4. `VITE_UNIFY_PREDICATE_SLM` 기본 off — 켜지 않아도 1단계 동작.
