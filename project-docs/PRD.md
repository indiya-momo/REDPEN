## 1. 한 줄 정의

> **AI 문장 교정이 아니라**, 조판·텍스트 PDF에서 **맞춤법·띄어쓰기·표기 일관성을 자동 탐지**하고 **PDF 위에 위치를 표시**하는 **브라우저 로컬** 검수 도구.

**포지셔닝:** 맞춤법 앱 대체 X → **PDF 교열 전처리 스캐너** · 장기적으로 **작품별 표기 기준(프로젝트) 관리**.

**방향 (2026-11, 계획):** 탐지 결과를 편집자가 확인·처리하는 **반자동 편집기** — 검색·주석·표준국어대사전 연동 (§5.8). 아직 출시 기능 아님.

### 5.0 기준 산정 (코드 기준 2026-11)

- **프로젝트(저장한 기준):** 무료 1 · 유료 3 (`criteriaPresetLimit.js`) — [`criteria-count-model.md`](criteria-count-model.md)

- **표기 통일 탭 등록 상한** (`consistencyRuleLimit.js`):

- **PDF 용량:** 50MB 초과 경고 · 브라우저 검수 상한 **100MB** · TXT 변환 상한 **150MB** (`pdfSizeLimits.js`)

### 5.2 베타 보완 (진행)

- 베타 피드백 기반 UX·안내·막힘 지점 수정  
- PostHog: `check_run`, 저장, 이탈, PDF 재업로드·재방문, 외래어·통일형 대시보드, 테스터 `is_internal` 구분  
- 한글에서 저장한 **PDF 샘플** 품질 이슈 수집 ([`input-format-strategy.md`](input-format-strategy.md))  
- 주의 규칙 `except` 등 데이터 보정 (매칭 로직 변경은 freeze 하에 — freeze 문서 유효성 **확인 필요**, §6)

**알려진 이슈 (2026-11-20)**

- **Kiwi 서버 형태소 분석** `/api/kiwi/analyze` — 배포 사이트에서 `FUNCTION_INVOCATION_FAILED`. 프로덕션 클라이언트는 `VITE_KIWI_ANALYZE_ENDPOINT`가 없으면 서버를 부르지 않음 → 배포판에서 Kiwi 의존 경로(본조 2차 긴 합성어 일부, 표기 통일 잡음 2차 등)가 실제로 동작하는지 **확인 필요**. 기능이 아니라 이슈로 관리.  
- **`api/stdict.js`**(표준국어대사전 API 프록시) — 존재하지만 현재 화면에서 호출하지 않음. 로그인 확인·호출 제한 없음(5분 캐시만). 다시 쓰려면 보호 장치 필요.

### 5.3 유료화

**코드에 들어간 것 (2026-11):**

| | 무료/베타 | 유료 (`plan: paid`) |
|--|-----------|---------------------|
| 프로젝트(저장 기준) | 1 | 3 |

| 검수 결과 자동 보관·재다운로드 (30일) | ❌ | ✅ |

- 가입 보너스 검수권은 **지급 중단** (`SIGNUP_BONUS_TAB_CHECKS = 0`). 일일 미사용분은 이월 안 됨.  
- **결제 미연동** — 유료 전환은 관리자 이메일 등록(Callable)으로만.  
- **가격:** 기존 안(7,900원 / 10,900원 팀)은 코드에 없음 — **확인 필요**. 팀 플랜 구분도 코드에 없음.

**공유:** 실시간 협업 없음. 링크 = 읽기 전용 스냅숏 → 수신자 프로젝트 슬롯에 **복사**.

*띄어쓰기 이형태 기준의 「표기 통일 추천」은 출시됨(§5.1 #7). 아래는 고유명사·이름 엔티티 확장.*

## 6. 비목표

### MVP·베타 (유지)

- AI 자동 교열 · 문장 추천  
- **자동 수정 저장 · 원고 텍스트 재작성·PDF 재조판** — *원본 PDF에 주석을 덧붙인 사본 내보내기(§5.1 #11)는 함. 본문 텍스트는 어떤 경우에도 자동으로 고치지 않음*

- 실시간 협업 · 공동 편집

- `ruleEngine` · regex · spelling/caution 매칭 로직  
- `MainScreen` dead props 대규모 제거
