# 표기 통일 추천 — 규칙 1차 + 표준국어대사전 2차

**상위:** `unify-predicate-review-slm-design-2026-07-30.md`  
**상태:** 합의 · **구현됨** (플래그 `VITE_UNIFY_STDICT`, 기본 off) · 2026-07-31  
**결정:** UI 목록 **이동(A)** — 사전이 용언이면 명사 자리에서 용언 쪽으로 옮김.  
**SLM:** 이번 범위 밖 (`VITE_UNIFY_PREDICATE_SLM` 기본 off 유지).

---

## 0. 목표

규칙만으로는 `그러다@`가 명사 칸에 남는 구멍을, **표준국어대사전 Open API**로 보완한다.  
전부 사전·전부 SLM이 아니라 **규칙으로 먼저 나눈 뒤, 사전으로 재분류**한다.

성공 예 (실측 20건):

| 입력 | 규칙 | 사전 | UI |
|------|------|------|-----|
| `공개@` | 명사 | 명사(`공개`) | 명사 계열 유지 |
| `그러다@` | 명사 | 용언(`그러다`) | **용언 쪽으로 이동** |
| `가정해 보자` | 용언 | `가정해`→`가정하다` 동사 | 용언 유지 |
| `돌아가@` | 용언 | `돌아가`→`돌아가다` | 용언 유지 |
| `연방준비제도이사회` | 명사 | 미등재 | **유지**(삭제 안 함) |

## 1. 파이프라인

```
그룹핑
  → 의존명사+의 strip (기존)
  → 규칙 triage (명사 / 용언(추정))  (기존)
  → 사전 재분류 (신규)           ← 명사·용언(추정) 그룹 어근
  → 목록 재배치 (A)              ← 용언이면 series/single → predicate 버킷
  → 2차 검토 요약 갱신
  → (옵션) 조사 SLM / 용언 SLM   ← 기존 플래그, 변경 없음
```

---

## 2. 사전 조회 규칙

1. **조회 단위** = 화면 그룹과 동일 (계열 affix 1, 띄어쓰기 카드 hangul 어근 1).  
   보조용언 카드는 **본용언 쪽**만 (`가정해`, 전체가 아님).
2. **1차 쿼리** = 어근 그대로, `method=exact`, `type1=word`.
3. **2차 쿼리** = 1차가 0건이고, 규칙상 용언(추정)이거나 활용형처럼 보일 때만  
   기본형 후보(`가정하다` 등). **명사 칸에 `하다`를 붙이지 않음** (`공개` ↛ `공개하다`).
4. **판정**
   - 품사에 동사·형용사·보조* → **용언**
   - 명사·의존명사 등만 → **명사**
   - 둘 다 → **혼재** → 목록 **유지**(안전)
   - 미등재·HTTP/키 실패 → **유지**
5. **용언 판정 시 (A):** 해당 그룹/클러스터를 UI에서 **용언 구간으로 이동**.  
   명사 판정·미등재는 자리 유지. **목록에서 삭제하지 않음.**

---

## 3. 배관·보안

- 브라우저에 키 노출 금지. Vite 프록시 또는 `api/` 라우트  
  예: `/api/stdict/search` → `https://stdict.korean.go.kr/api/search.do`  
  서버 env: `STDICT_API_KEY` (사용자가 발급한 표준국어대사전 키).
- `.env.example`에 이름만 문서화. 실키 커밋 금지.
- 플래그: `VITE_UNIFY_STDICT=true` 일 때만 호출 (기본 off 권장 → 키 있는 로컬·스테이징에서 on).  
  또는 키 있으면 자동 on — 구현 시 **플래그 명시 on**으로 단순화.

## 4. DEV 「2차 검토」카피

요약 예:

`2차 검토 결과 : [명사] N건, 용언(추정) N건`  
(+ 제외·사전이동이 있으면 짧게 부기 가능)

본문(있을 때만):

- 제외(규칙) …
- **사전: 명사→용언 이동** (예: `그러다@`)
- 사전 미등재/실패(참고)는 필수는 아님(노이즈면 생략)

- 사전 미등재 자동 삭제

## 6. 성공 기준

1. `공개@`는 명사 계열에 남고, 조회 키가 `공개하다`가 되지 않는다.  
2. `그러다@`는 사전 후 **용언 구간**으로 옮겨지고, 요약 건수가 맞다.  
3. `개의@`는 기존처럼 규칙 제외.  
4. 키 없거나 플래그 off면 **지금과 동일**(규칙만).  
5. 실키·프록시로 20건급 재현 시 체감 수 초~십수 초(로컬 SLM 대비).
