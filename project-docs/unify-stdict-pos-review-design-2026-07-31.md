# 표기 통일 추천 — 규칙 1차 + 표준국어대사전 2차

**상위:** `unify-predicate-review-slm-design-2026-07-30.md`  
**상태:** 합의 · **구현됨** (플래그 `VITE_UNIFY_STDICT`, 기본 off) · 2026-07-31  
**결정:** UI 목록 **이동(A)** — 사전이 용언이면 명사 자리에서 용언 쪽으로 옮김.  
**SLM:** 이번 범위 밖 (`VITE_UNIFY_PREDICATE_SLM` 기본 off 유지).  
**개정:** 2026-07-31 — 1차 `@` 채움 다수결 → 용언은 **사전형**·명사는 **그대로** 조회.

---

## 0. 목표

규칙만으로는 `그러다@`가 명사 칸에 남는 구멍을, **표준국어대사전 Open API**로 보완한다.  
전부 사전·전부 SLM이 아니라 **규칙으로 먼저 나눈 뒤, 사전으로 재분류**한다.

성공 예:

| 입력 | 1차(규칙) | 사전 쿼리 | 판정 | UI |
|------|-----------|-----------|------|-----|
| `공개@` | 명사 | `공개` (그대로) | 명사 | 명사 계열 유지 |
| `그러다@` | 용언(추정)·또는 명사→사전 | `그러다` | 용언 | **용언 쪽으로 이동** |
| `가정해 보자` / `계산해보자` | 용언 | `계산하다` (사전형) | 용언 | 용언 확인 |
| `답해보자` | 용언 | `답하다` | 용언 | 용언 확인 |
| `날아@` | 용언 | `날다` (사전형) | 용언 | 용언 확인 |
| `들어@` | 용언 | `들다` | 용언 | 용언 확인 |
| `대어@` | 용언 | `대다` (※ `대어` 명사 exact에 안 묶임) | 용언 | 용언 확인 |
| `밀려@` | 용언 | `밀리다` → `밀다` | 용언 | 용언 확인 |
| `돌아가@` | 용언 | `돌아가다` | 용언 | 용언 유지 |
| `연방준비제도이사회` | 명사 | 그대로 · 미등재 | — | **유지**(삭제 안 함) |

## 1. 파이프라인

```
그룹핑 (+ 조사·보조 힌트)
  → 의존명사+의 strip (기존)
  → 규칙 triage (명사 / 용언(추정))
       · 계열: `@` 채움말 다수결 (보조·용언 vs 명사) → dictPos
       · 단일: affix/키 휴리스틱 (기존)
  → 사전 재분류
       · 명사 → 어근 그대로 exact
       · 용언 → 사전(기본)형 우선 exact
  → 목록 재배치 (A)              ← 용언이면 series/single → predicate 버킷
  → 2차 검토 요약 갱신
  → (옵션) 조사 SLM / 용언 SLM   ← 기존 플래그, 변경 없음
```

구현: `unifyListStemTriage.js` (`markSeriesBySlotMajority` 등), `unifyStdictPos.js` (`buildStdictQueryList` · `lemmaCandidatesForConjugation`).

---

## 2. 1차 규칙 — 계열 `@` 채움 다수결

접두 `과학@` / 접미 `@…` 에서 **affix만** 보지 않고, `@` 자리에 오는 채움말을 센다.

| 채움 신호 | 집계 |
|-----------|------|
| `auxReview`(본용언+보조 시트) 또는 용언형 휴리스틱 | 용언(보조) 쪽 |
| 명사로 보이는 채움 | 명사 쪽 |

- 용언(보조) **다수** → 계열을 **용언(추정)** (`dictPos: predicate`)
- 명사 **다수** → **명사** (`dictPos: noun`)
- 동점·채움 없음 → affix 휴리스틱(`만들어@` / `문화@`)으로 폴백

이 결과가 DEV 요약 `[명사] N · 용언(추정) N` 과 목록 정렬·사전 `allowLemmaTry`에 쓰인다.

## 3. 사전 조회 규칙

1. **조회 단위** = 화면 그룹과 동일 (계열 affix 1, 띄어쓰기 카드 hangul 어근 1).  
   보조용언 카드는 **본용언 쪽**만 (`가정해`, 전체가 아님).
2. **명사(1차)** → 쿼리 = 어근 **그대로**. `하다`를 붙이지 않음 (`공개` ↛ `공개하다`).
3. **용언(1차)** → 쿼리 = **사전형 우선**, 동사 히트면 즉시 확정.  
   활용형 exact를 먼저 쓰지 않음 — `대어` 명사에 묶인 뒤 `대다`를 안 보는 문제를 막는다.  
   사전형 후보 예 (`lemmaCandidatesForConjugation`):
   - `…해보자` → `…하다` (`계산해보자`→`계산하다`, `답해보자`→`답하다`)
   - `…해` → `…하다` (`가정해`→`가정하다`)
   - `…아가/어가…` → `…다` (`돌아가`→`돌아가다`)
   - `…려` → `…리다`, `…다` (`밀려`→`밀리다`/`밀다`)
   - `…아/어/여…` → 끝 음절 제거 + `다` (`날아`→`날다`, `들어`→`들다`, `대어`→`대다`)
   - 이미 `…다`면 그대로
   - 사전형 전부 미등재 시에만 원형(활용형) 폴백
4. **판정**
   - 품사에 동사·형용사·보조* → **용언**
   - 명사·의존명사 등만 → **명사**
   - 둘 다 → **혼재** → 목록 **유지**(안전)
   - 미등재·HTTP/키 실패 → **유지**
5. **용언 판정 시 (A):** 해당 그룹/클러스터를 UI에서 **용언 구간으로 이동**.  
   명사 판정·미등재는 자리 유지. **목록에서 삭제하지 않음.**

## 4. 배관·보안

- 브라우저에 키 노출 금지. Vite 프록시 또는 `api/` 라우트

- 플래그: `VITE_UNIFY_STDICT=true` 일 때만 호출 (기본 off 권장 → 키 있는 로컬·스테이징에서 on).

## 7. 성공 기준

1. `공개@`는 명사 계열에 남고, 조회 키가 `공개하다`가 되지 않는다.  
2. `그러다@` / `날아@` / `들어@` / `대어@`는 사전 후 **용언**으로 잡히고, `대어` 명사 exact에만 묶이지 않는다.  
3. `개의@`는 기존처럼 규칙 제외.  
4. 키 없거나 플래그 off면 **규칙 1차만**(사전 생략).  
5. 실키·프록시로 20건급 재현 시 체감 수 초~십수 초(로컬 SLM 대비).
