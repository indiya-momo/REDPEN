PDF를 올리고 맞춤법 탭에서 기준 검수를 누르면 됩니다. 처음에는 맞춤법 검수만 해 보시기를 권합니다.

## 준비물

- PC의 Chrome 권장
- 텍스트를 선택할 수 있는 인디자인·한글 PDF(100MB 이하)

## 순서

### 1. PDF를 올립니다

작업 화면에서 「PDF 파일을 브라우저에 업로드」를 눌러 원고를 올립니다.

![1 — PDF 업로드](help-image:01-upload.png)
*① PDF 파일을 브라우저에 업로드*

### 2. 맞춤법 탭을 확인합니다

왼쪽에서 맞춤법 탭과 검수 기준을 확인합니다.

![2 — 맞춤법 탭](help-image:02-spelling-tab.png)
*② 맞춤법 탭 (원고 출처: 한국관광공사)*

### 3. 기준 검수를 누릅니다

![3 — 기준 검수](help-image:03-run-check.png)
*③ 기준 검수 (원고 출처: 한국관광공사)*

### 4. 결과를 확인합니다

왼쪽에 검수 결과, 오른쪽에 원고가 나타납니다. 결과 카드의 쪽 번호를 누르면 원고의 해당 위치로 이동하고, 확인할 곳에 하이라이트가 표시됩니다. 결과를 확인하고 편집할 내용을 선택합니다.

![4 — 검수 결과](help-image:04-result.png)
*④ 쪽 번호를 누르면 원고의 해당 위치로 이동합니다 (원고 출처: 한국관광공사)*

## 검수 화면은 어떻게 읽나요?

왼쪽은 검수 결과 목록, 오른쪽은 실제 원고입니다. 두 화면을 오가며 확인합니다.

### 왼쪽: 검수 결과

찾아낸 항목이 종류별로 묶여 목록으로 나옵니다. 항목을 누르면 오른쪽 원고의 해당 위치로 이동합니다.

### 오른쪽: 원고

올린 PDF가 그대로 나오고, 확인할 구간에 하이라이트가 표시됩니다. 확대·축소와 페이지 이동은 위아래 컨트롤로 합니다.

![01 — 검수 화면](help-image:getting-started/panels/01-panels.png)
*왼쪽은 검수 결과, 오른쪽은 원고입니다 (원고 출처: 한국관광공사)*

<!-- 동영상 자리: 첫 검수 30초 -->

> **참고** — 인디야는 문장을 자동으로 고치지 않습니다. 검수 결과는 참고 자료이며, 최종 판단과 반영은 담당자가 합니다.
