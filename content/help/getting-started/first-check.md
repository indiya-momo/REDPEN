인디야는 브라우저에서 인디자인 PDF를 열고, 선택한 기준에 따라 맞춤법·표기를 검수하는 프로그램입니다. 처음에는 맞춤법 검수만 진행해 보시는 것을 권장합니다.

## 준비

- PC의 Chrome 또는 Edge 브라우저
- 텍스트가 선택·추출되는 인디자인 PDF (100MB 이하)

## 기본 순서

1. 작업 화면에서 PDF를 업로드합니다.
2. 왼쪽에서 맞춤법 탭과 검수 기준을 확인합니다.
3. 기준 검수를 실행합니다.
4. 왼쪽에 검수 결과, 오른쪽에 반영 원고가 표시됩니다.
5. 결과를 확인한 뒤, 필요한 부분만 원고에 반영합니다.
