인디야의 일부 검사 기능은 국립국어원 『표준국어대사전』 데이터를 가공해 씁니다.
가공한 데이터 파일과 사용 안내는 로그인한 뒤 **마이페이지 「회원 정보」** 아래 「표준국어대사전(26/10/16) 데이터와 사용 안내」 카드에서 내려받을 수 있습니다.

- GoldenDict(StarDict)에서 바로 읽는 사전 zip, 품사 색인, 용언 추출본, 링크 색인, 두음 표제어와 출처·라이선스 고지를 받을 수 있습니다.
- 받은 파일을 다시 배포하거나 고치실 때는 출처를 밝히고 같은 라이선스(CC BY-SA 2.0 KR)를 지켜 주십시오.
- 파일은 원본 사전 전체가 아니라 검사에 쓰는 가공본입니다.
