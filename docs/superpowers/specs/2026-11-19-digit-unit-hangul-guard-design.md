# 수·단위 한글 수사 가드 (digitUnitSpacing · 제43항)

**날짜:** 2026-11-19  
**상태:** 1차 합의 (문서화 후 구현)  
**대상:** `src/lib/digitUnitSpacing.js` (+ 테스트)  
**관련:** 맞춤법 제43항, `VITE_SPACING_CATEGORY` 띄어쓰기 폴더, spacing-folder 스펙

## 문제

한글 수사+단위 붙여쓰기 검출(경로 3)이 **정규식만**으로 동작해 다음이 발생한다.

- 단어 중간 절단: `인사도` → `사도`→`사 도`
- 사전·관용어: `한쪽`·`사도`·`한번` 등
- 단위 뒤 한글 이어짐: `한개인`·`두개골`·`십자가` (오른쪽 경계 없음)

형태소·전체 사전 핫패스는 1차에서 쓰지 않는다.

## 목표 (1차)

1. 왼쪽·오른쪽 경계로 중간 절단·어절 내부 확장을 막는다.
2. 수사×단위 **허용 매트릭스**로 오탐을 구조적으로 줄인다.
3. 잔여 동형이의어는 **except 데이터**로 보정한다 (주의 규칙 `except` 방침과 동일 취지).
4. 검출 유지: `삼백명`·`2천년`·`한개`·`수백명`·`삼십분`·`몇백명이`·**`천년`**.

## 비목표 (1차)

- Kiwi·표준국어대사전 **핫패스** 조회
- `UNITS` 목록 대폭 확장 (마리·그루·학년 등) — **기존 UNITS만** A/B/C/D 분류
- `여러` 접두 추가
- `ruleEngine` / 맞춤법·caution 시트 변경

## 베타 freeze

- freeze 핵: `ruleEngine`·맞춤법/caution **시트** 매칭.
- 본 모듈은 시트 밖·플래그 게이트 2차 경로. **엔진·시트 비침인 가드·except 데이터 수정으로 명시 진행.**

---

## 1. 경계

### 왼쪽

`(?<![가-힣0-9])` 를 **수사 헤드 전체**(수·몇 접두 포함) 앞에 둔다.

- 유지: `수백명`·`수천년`·`몇백명`
- 차단: `인사도`의 `사도`
- 감수 미탐: `약삼백명` (앞말 부착)

### 오른쪽

단위 직후는 다음만 허용한다. `(?![가-힣])` 단독 금지 (`삼백명이` 미탐 방지).

- 문자열 끝
- 비한글
- **조사·어미 허용 목록** 뒤 비한글/끝:  
  `이|가|은|는|을|를|의|에|도|만|씩|이나|으로|로부터|부터|까지|께|께서|에게|한테|보다|처럼|만큼|밖에|조차|마저|뿐|마다|쯤|정도|이상|이하`

예: `몇백명이` 검출, `한개인`·`두개골` 미검출.

경로 2(만·억·조)에도 같은 좌·우 경계를 적용한다.

---

## 2. 수사 분류

| 코드 | 정의 | 예 |
|------|------|-----|
| **N1** | 고유어 수관형사 + `몇` | 한·두·세·…·열·스무…, 몇 |
| **N2** | 한자어 한 글자 (일~구만) | 일·이·삼·사·오·육·칠·팔·구 |
| **N3_MULTI** | 십·백·천·만 포함이거나 두 글자 이상 한자어 수 / 앞자리 아라비아 | 이십·삼백·수백·몇천·2천·수천 |
| **N3_ALONE** | 단독 십·백·천·만 | 십·백·천·만 |

앞자리 숫자만 있는 헤드(`15`)는 기존대로 띄어 제안하지 않는다.

## 3. 단위 분류 (현재 UNITS만)

| 군 | 단위 | 성격 |
|----|------|------|
| **A** | 명·개·권·곳·원·톤·그램·리터·킬로미터·센티미터·밀리미터·킬로그램·밀리그램·퍼센트·달러·유로·엔·초 | 수량·계량, 겹침 적음 |
| **B** | 도·쪽·분·세·시·장·편·점 | 단음절·일반어 겹침 |
| **C** | (이번 UNITS에 없음 — 학년·층 등은 미수록) | 순서·번호, 붙여 허용 |
| **D** | 월·일 | 날짜·등재어 겹침 |
| **Y** | 년 | 별도 행 (아래 매트릭스) |

## 4. 허용 매트릭스

| | A | B | C·D | Y(년) |
|--|---|---|-----|-------|
| **N1** | 허용 | 제외 | 제외 | 허용 |
| **N2** | 제외 | 제외 | 제외 | 제외 |
| **N3_MULTI** | 허용 | 허용 | 제외 | 허용 |
| **N3_ALONE** | 허용 + except | 제외 | 제외 | 허용 + except† |

† **천년은 except에 넣지 않고 검출 유지** (제43 수량 예시·최초 요구). 표준국어대사전 명사「천년」(千年 등)과 동형 — 잔여 오탐으로 감수, 사전 후처리는 이후.

---

## 5. except (1차 데이터)

표준국어대사전 API 대조(2026-11-19) 후 확정.

| 표면 | 이유 | 1차 |
|------|------|-----|
| 천명 | 天命 등 등재 | except |
| 만개 | 滿開 등재 | except |
| 만원 | 滿員·滿願 등재 | except |
| 만년 | 등재 | except |
| 만권 | 등재 | except |
| 천개 | 등재 | except |
| 천년 | 등재 있으나 수량 검출 우선 | **검출 유지** |
| 백년·십년 | API 검색 0 | except 불필요 |

경로 2의 단독 `만|억|조` 스킵은 유지 (`만원` 등).
