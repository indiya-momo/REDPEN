# 본조 — 아/어가 아닌 연결 + 보조용언 띄어쓰기 필수

**날짜:** 2026-11-18  
**상태:** 설계 승인 (개정본 · 2026-11-18)  
**관련 UI:** `space-required-non-aeo` — 「본용언이 (-아/-어)가 아닌 경우 : 띄어쓰기 필수」

## 문제

- UI에 해당 체크 줄이 있으나, 실제로는 3음절 복합어 묶음과 item을 공유하는 **안내만** 있고 전용 검사가 없다.
- `-지 말다`처럼 **앞이 아/어가 아닌** 보조용언 구성은 붙여 쓸 수 없는데, 지금 1차 stem은 거의 전부 `어 가`·`아 하` 형태라 비아/어 붙임(`뛰지말라` 등)이 목록에 안 오른다.

## 합의된 목표

켠 보조용언에 대해:

1. **보조용언** 후보인지 본다 (체크된 본조 항목의 꼬리만).
2. **사전 등재**인지 본다.
3. 앞이 **닫힌 비아/어 연결어미 집합**에 해당하고, 사전에 **없으면** → **띄어쓰기 필수**로 지적한다.
4. 사전 등재면 → 기존 붙임 합성어와 같이 **지적에서 빼거나 합성어로만 표시**.

`-지 말다` 단독 규칙이 아니라, **비아/어 연결 + 보조** 일반 검사다.  
다만 첫 릴리스 후보는 「아/어가 아니면 전부」가 아니라 **닫힌 연결어미 집합 바로 뒤**로 좁힌다 (오탐 완화 · 시트 stem 대량 추가 없음).

## 비목표 (이번 범위 밖)

- 1차 `ruleEngine` / 띄움 stem 찾기 변경
- 비아/어 stem 시트 전면 추가 (나중 보강만)
- Kiwi로 아/어 연결 어미 판정
- 표기 통일 연동
- 화면 ↔ PDF 교정본 기준 맞추기 (별도 작업)

## 결정 요약

| 항목 | 결정 |
|------|------|
| 대상 보조용언 | **체크(enabled)된 본조 항목**만 |
| 후보 앞형태 (1차 릴리스) | **닫힌 비아/어 연결어미** 바로 뒤만 (`-지`, `-게`, `-고`, `-도록` 등 — 구현 전 목록 확정). 「아/어가 아니면 전부」 아님 |
| 아/어·축약 제외 | 시트 stem 앞조각 + 축약형(`해`, `봐`, `줘`, `와`, `써` …)을 **아/어 쪽**으로 두어 이 패스에서 제외. 제외된 표면은 **기존 본조 경로가 잡는지** 테스트로 보장 |
| 비아/어 찾기 | **켠 꼬리의 붙여 쓴** 자리 중, 직전이 닫힌 연결어미인 것만. 자주 빠지면 나중에 stem 보강 |
| 사전 등재 시 | **A** — 합성어 처리 (필수 띄움 지적 제외/합성어 표시), 기존 `auxiliaryDictSolid` 경로 재사용 |
| 부착 층 | **2차만** (1차 비용 변화 없음) |
| UI 스위치 | **전용 itemId** (`space-required-non-aeo`). 3음절 복합어와 item 공유 금지. **기본 off**. 저장 설정 마이그레이션: 옛 공유 줄이 켜져 있어도 새 검사가 갑자기 대량 켜지지 않게 처리 |
| 결과 그룹 key | 재실행·수락/무시 유지 가능하도록 **안정적 itemId·표면 키** |

## 접근 (채택 = 안 1 + 후보 축소)

1. **채택 — 2차 전용 패스 + 닫힌 연결어미 필터**  
   켠 보조 꼬리 붙임 → 직전이 닫힌 비아/어 어미 → 사전 → 미등재만 띄움 필수.
2. 기각 — 「아/어가 아니면 전부」 개방 후보 (하다/보다/주다 오탐·접미사 `-하다` 폭주).
3. 기각 — 시트 비아/어 stem 대량 + 1차 찾기.
4. 기각 — 기존 아/어 붙임 2차만 재분류.

## 흐름

```text
본조 검사 완료
  → non-aeo 전용 item 켜짐?
       → 켠 보조용언 item의 꼬리(활용형 포함)로 붙여 쓴 후보 수집
         · 어절 경계 확인 (짧은 꼬리 부분일치 방지)
       → 직전이 닫힌 비아/어 연결어미가 아니면 제외
       → 직전이 아/어·축약 집합이면 제외 (기존 경로에 맡김)
       → 사전 등재? → 합성어 (필수 띄움 지적 아님)
       → 규정상 붙여 쓰기 허용 구성(의존명사+하다/싶다 등) → 제외 목록
       → 미등재 → 본조 결과에 「띄어쓰기 필수」(띄움 제안)
```

## 모듈 경계 (구현 시)

- **새 2차 모듈:** non-aeo 붙임 후보 · 닫힌 어미 판정 · 아/어·축약 제외. 1차 `ruleEngine` 비침.
- **사전·기본형:** 기존 `auxiliaryDictSolid` / 꼬리→기본형 경로가 아/어 경로와 **동일하게** `말라→말다` 복원하는지 확인·재사용. 조회 캐시 유지.
- **꼬리 매칭:** `auxiliarySearchTailsFromBonBojoItem`(또는 동일 facade). 짧은 활용형은 **어절 경계** 필수.
- **배선:** `useRuleCheck` 본조 enrich에서 glue → dict 옆/직후. 전용 item off면 no-op.
- **UI:** `space-required-non-aeo` = 전용 itemId. `SPACE_REQUIRED`(3음절)와 item 분리.
- **표시:** 기존 본조 띄움/붙임·합성어 요약·오버레이 관례 (새 탭 없음).

## 성공 기준 (양성)

- `뛰지말라` 유형: 해당 보조가 **켜져 있고** non-aeo가 켜져 있으며 사전 미등재면 결과에 뜸.
- 사전 등재면 필수 띄움으로 안 올리거나 합성어로만 표시.
- 아/어+보조(`쉬어가라고` 등)는 이 패스가 **다시 집어 올리지 않음**.
- 끈 꼬리는 후보에 없음.
- 1차 찾기 건수·시간 변화 없음.

## 성공 기준 (음성 · 리뷰 반영)

- `공부하다` 등 **접미사 `-하다`** 구성 → 이 패스 지적 아님 (연결어미 필터·사전·제외로 탈락).
- **의존명사 + 하다/싶다** (`-ㄴ 듯하다`, `-ㄹ 만하다` 등, 제47항 계열) → 붙여 쓰기 허용이면 제외. **구현 전 국어원 규정으로 목록 확정.**
- 축약 아/어 (`해봐`, `줘봐` 등) → 비아/어로 오분류하지 않음; 필요 시 기존 본조 경로 담당.
- 「이 패스에서 아/어로 제외」한 표면은 **기존 본조 경로가 반드시 잡거나, 의도적 비대상**임을 테스트로 확인 (사각지대 방지).

## 구현 전 점검

- 실제 원고 1~2건에서, 켠 꼬리 기준 **닫힌 어미 필터 전/후 후보 수**를 대략 센다 (오탐 규모 가늠). 다른 PDF는 **사용자 허락 후**만.
- 닫힌 연결어미 초안 목록 + 제47항 제외 목록을 규정 확인 후 스펙/코드 상수로 고정.

## 나중에

- 스캔으로 자주 빠지는 비아/어만 stem 보강.
- 연결어미 집합 확대는 **원고 후보 수·오탐** 본 뒤.
- Kiwi는 기본 경로 아님.
