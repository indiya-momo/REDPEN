# 경주멍 줄잇기 — 인디야가 못 잡는 것 중 시스템화 가능분

**날짜:** 2026-11-19  
**상태:** 1번 완료 · 2번 중 `만큼`·`위엄있`만 구현  
**자료:** 경주멍 줄잇기 작업파일(2026-11-18) `aiResults` 62건  
**규범:** 한글 맞춤법만 (세종 표기법 비사용)

## 범위

줄잇기가 표시한 지적 중, **지금 인디야 맞춤법 시트 + 띄어쓰기 폴더 3묶음**이 못 잡고, **AI·문맥 없이** 닫힌 규칙·정규식으로 돌릴 수 있는 것만 다룬다.

`ruleEngine`·시트 매칭 코어는 건드리지 않는다. 새 검출은 띄어쓰기 폴더 2차 모듈.

## 이미 잡힘 (이번 작업 제외)

| 표면 | 경로 |
|------|------|
| `천년`·`천년을`·`천년도` 등 | 수·단위 `digit-unit` (폴더 켜짐) |
| `잊어버린걸까`·`될수` | 의존명사·-ㄹ까 보다 |
| `날개짓` | 맞춤법 시트 |

코드만 있고 폴더 미편입: `뛰지말라`·`해보이`·`어루만져주세요`·`싶었나봐`(`official-aux`), `붉은 빛`·`불꽃 같은`(`noun-pred`). **이번 1번 아님.**

## 시스템화 목록

### 1. 문장부호·공백 (이번 구현)

| 예 | 제안 | 패턴 요지 |
|----|------|-----------|
| `.반가운` `있었습니다.우리가` | 종결 뒤 한 칸 | 한글 `.?!…` 직후 한글 (같은 줄만) |
| `,오래` `,남겨진` | 쉼표 뒤 한 칸 | 한글 `,` 직후 한글 |
| `《경주멍》 은` | `》은` | 닫는 `」』》)` + 공백 + 조사 |
| `내함· 사리병` | `내함·사리병` | `·` 뒤 공백(앞은 붙임) |
| `16.5.cm` | `16.5cm` | 소수 + 중복 `.` + 단위 |

**가드**

- 줄바꿈 뒤 한글은 새 문단으로 보고 종결-공백 미적용
- `1,500`·`16.5cm`는 미매칭
- `》 은은히`처럼 조사 뒤 한글이 이어지면 미적용

**부착:** 띄어쓰기 폴더 묶음 `punct`(문장부호). 기본 끔. `findHits`만, 페이지 전체 추가 스캔 없음.

**비목표:** `지요` 뒤 마침표 삽입, `「」` 짝 자동 수정, URL.

### 2. 시트·닫힌 표면

**이번에 넣음** (`adnominalDependentNoun`, 의존명사·-ㄹ까 보다 묶음)

| 예 | 규칙 |
|----|------|
| `잊을만큼` → `잊을 만큼` | 관형사형(을/은/는/던·ㄴ·ㄹ 받침) + 의존명사 `만큼`. `이만큼`·`그만큼` 등 부사 제외 |
| `위엄있` → `위엄 있` | 명사+있다 **닫힌 표면만**. `재미있다`는 유지 |

**아직 안 함:** `오래 된`·`다보면`·`’하며`·`새겨넣`·`쉬어가고`·`넘어서`(붙임)·`수수께기`·`푸른 빛`·`뜯겨지고`  
→ 시트 행 또는 기존 모듈 한 줄. 엔진 변경 없음.  
체언+만큼(`키만큼`)·열린 명사+있다 패턴은 이번 밖.

### 3. 관형사·의존명사 (except 후)

`그줄을`·`이질문을`·`무릎위에`·`나뭇가지모양`  
→ 1차는 시트 표면만. 열린 `그+명사` 스캔은 except 없이 보류.

### 4. 표시만

닫는 `」` 없음 → 검출 가능, 자동 수정 없음.

## 시스템화하지 않음

문장 호응·호격 쉼표·`인데도 불구하고`·`살포시`/`살며시`·제목·행정구역·캡션 혼입·숫자 탈락·유물명(`금 관꾸미개`).  
`찍혀있습니다`는 제47항 붙여 허용 → 오류로 넣지 않음.
