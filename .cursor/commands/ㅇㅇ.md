# 진행 (합의된 작업 구현)

워크스페이스: `pdf-publish-proofread` (PC worktree). **직전 대화에서 합의·승인된 범위만** 구현한다.

## 의미

「진행하자」「적용하자」= 설계·의견 교환 후 **OK 난 내용을 코드로 반영**.  
커밋(`/커`)·배포(`/배`)는 **포함하지 않음** — 사용자가 따로 요청할 때만.

## 범위

- 방금 논의한 체크리스트·프롬프트·수정안을 **그대로** 따른다.
- `welcome-pc` 작업 시 `welcome-mo` / `src/welcome/mobile/**` 는 건드리지 않는다.
- beta freeze: ruleEngine·MainScreen props 대규모 변경·`docs/` 수동 수정 금지.
- 요청 밖 리팩터·顺便 개선·불필요한 테스트 추가 금지.

## 절차

1. 직전 맥락에서 **구현 대상**과 **건드리지 말 것**을 한 줄로 확인한다.

2. 관련 파일만 읽고 **최소 diff**로 구현한다.

3. CSS/UI면 `npm run dev`(5173)로 PC 대문·해당 화면만 확인한다 (필요 시).

4. 에셋(누끼 PNG 등)이 코드만으로 불가하면: 가능한 범위까지 구현 후 **파일 준비 필요**만 짧게 알린다.

## 보고

- 체크리스트 항목별 완료/미완 (에셋 대기 등)
