# 카나나 로컬 켜기

워크스페이스: `pdf-publish-proofread` (PC worktree). **클라우드 GPU 등록 없음** — 이 PC만.

## 의미

사용자가 `/카` 또는 「카나나 켜기」→ **로컬 카나나 추론 서버를 실제로 켠다.** 설명만 하지 않는다.

## 절차

1. `8000` 포트 확인. mock(`josa-slm-mock`)이 점유 중이면 종료.
2. 백그라운드 기동:
   ```powershell
   cd C:\Users\gikan\Documents\pdf-publish-proofread
   .\.venv-kanana\Scripts\python scripts\kanana-openai-server.py
   ```
3. 로그에 `Ready on` / `Kanana OpenAI server` 나올 때까지 대기.  
   `GET http://127.0.0.1:8000/v1/models` → id에 `kanana-2-1.3b-instruct`(mock 아님) 확인.
4. `.env.local`에 `VITE_UNIFY_JOSA_SLM=true` 설정(없으면 추가).  
   Vite가 env를 반영하도록 **필요 시** `npm run dev` 재시작 (`:5173`).
5. 짧게 보고: 서버 ON · 플래그 ON · CPU면 건당 ~십수 초 · 표기 통일 찾기로 시험 가능.

## 끄기

「카나나 끄기」또는 `/카 끄기`면: `:8000` 프로세스 종료 + `.env.local`의 `VITE_UNIFY_JOSA_SLM=false` + Vite 재시작 안내.
